# Plans and pricing

| Plan | Price per technician per month | Includes |
|---|---|---|
| Starter | 19 USD | scheduling, mobile app, 120 API requests per minute |
| Growth | 39 USD | + route optimization lite, SSO, integrations |
| Enterprise | custom | + advanced routing, 24/7 support, 600 API requests per minute, data residency |

Add-ons: Route optimization (Growth), Platform tier (higher API limits), Advanced analytics.

Volume discounts start at 500 technicians. Discounts above 20% need approval from the sales manager.
